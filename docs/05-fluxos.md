# Fluxos passo a passo

## Visualizar clientes (estado atual)
1. Abra **Clientes** na navegação.
2. Pesquise por nome, serviço ou contato; selecione o filtro de status.
3. Alterne entre grade e lista.
4. Abra a ficha de um cliente demonstrativo para consultar os campos visíveis.
5. Se usar **Novo cliente**, preencha o formulário e confirme; o registro é local à sessão de UI e não deve ser tratado como cadastro persistente.

## Acompanhar oportunidades
1. Abra **Pipeline**.
2. Confira as colunas: Novo lead, Reunião, Proposta, Negociação, Contrato.
3. Consulte as oportunidades mostradas.
4. Crie uma oportunidade de exemplo pelo formulário.
5. Para tornar esse fluxo real, implementar persistência, autoria, registro de histórico e permissões.

## Acessar áreas futuras
1. Selecione Produção, Calendário, Arquivos, Financeiro ou Relatórios.
2. Verifique se a tela apresenta prévia ou mensagem de indisponibilidade.
3. Não cadastrar dados de cliente para operação real antes de validar armazenamento e controle de acesso.

## Mudança técnica
Alteração de fluxo deve atualizar `04-funcionalidades.md`, este arquivo, `03-dados-integracoes.md` e `CHANGELOG.md`.
